Menu **Dokumen Vendor** digunakan untuk mengunggah dokumen legal perusahaan dan melihat hasil review admin backoffice.

## Langkah-langkah

1. Buka menu **Dokumen Vendor**.
2. Temukan kartu dokumen yang ingin dilengkapi.
3. Tekan **Upload** atau **Upload Ulang**.
4. Pilih file dokumen yang benar dan masih berlaku.
5. Periksa nama file serta informasi masa berlaku yang ditampilkan.
6. Tunggu proses review admin dan periksa kembali status dokumen.

Untuk membuka file yang tersimpan, tekan tautan **Lihat file** pada kartu dokumen. Bagian **Dokumen Opsional Terupload** menampilkan dokumen opsional yang sudah diunggah.

## Jenis dokumen

| Dokumen | Keterangan |
| --- | --- |
| NPWP | Wajib |
| NIB | Wajib |
| SIUP | Wajib |
| PKP | Opsional |
| Rekening Bank | Wajib |
| Kontrak Kerja Sama | Opsional |
| Lainnya | Opsional |

## Yang perlu diperhatikan

> **Penting:** Pastikan file terbaca, sesuai jenis dokumen, dan masa berlakunya benar. Jangan mengunggah dokumen perusahaan ke kategori yang tidak sesuai.
