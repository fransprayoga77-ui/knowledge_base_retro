Panduan ini membantu Anda menjaga data pengemudi tetap lengkap dan berlaku.

## Langkah-langkah

1. Buka menu **Driver** dan cari nama driver pada kolom **Cari driver**.
2. Gunakan filter status jika ingin melihat driver dengan status tertentu.
3. Tekan ikon **Edit** untuk memperbarui informasi.
4. Tekan ikon unggah untuk mengelola dokumen apabila diperlukan.

## Data pada daftar driver

| Kolom | Keterangan |
| --- | --- |
| Driver | Nama pengemudi. |
| SIM | Nomor SIM dan tanggal kedaluwarsa. |
| Dokumen | Ringkasan kelengkapan dokumen, misalnya 4/4 approved. |
| Mobile | Informasi status mobile pada daftar. |
| Status Driver | Status operasional, misalnya Aktif. |
| Verifikasi | Status verifikasi, misalnya Verified. |
| Aksi | Tombol untuk mengubah data atau mengunggah/mengelola dokumen. |

## Yang perlu diperhatikan

> **Penting:** Perbarui data sebelum SIM atau dokumen kedaluwarsa.

## Kendala umum

| Kendala | Solusi |
| --- | --- |
| Driver belum terverifikasi | Periksa data driver, dokumen yang diminta, serta masa berlaku SIM. |
