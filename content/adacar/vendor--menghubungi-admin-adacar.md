Jika mengalami kendala, periksa beberapa hal berikut sebelum menghubungi admin Adacar.

## Kendala umum

| Kendala | Solusi |
| --- | --- |
| Assignment tidak ditemukan | Hapus kata kunci pencarian, ubah filter status, dan periksa kembali ID order. |
| Tidak dapat menerima assignment | Periksa status order, detail kebutuhan, ketersediaan unit, dan kemampuan pemenuhan vendor. |
| Unit tidak dapat dipilih | Periksa status verifikasi armada, dokumen kendaraan, dan rentang tanggal ketersediaan. |
| Dokumen belum disetujui | Periksa jenis dokumen, kualitas file, masa berlaku, dan status review admin. |
| Driver belum terverifikasi | Periksa data driver, dokumen yang diminta, serta masa berlaku SIM. |
| Settlement tidak terlihat | Periksa filter status, kata kunci, dan periode data yang tersedia. |
| Komplain tidak muncul | Periksa nomor case/order dan filter status yang dipilih. |
| Profil belum berubah | Periksa Riwayat Profil dan status persetujuan admin untuk perubahan data utama. |
| Gagal mengubah password | Pastikan password saat ini benar dan password baru sama dengan konfirmasinya. |

## Langkah-langkah

Sebelum menghubungi admin Adacar melalui kanal resmi:

1. Siapkan nama vendor dan akun yang digunakan.
2. Sertakan ID order, nomor polisi, atau nama driver sesuai kendala.
3. Catat waktu kejadian dan langkah yang sudah dicoba.
4. Lampirkan screenshot atau dokumen pendukung jika diperlukan.

## Yang perlu diperhatikan

> **Penting:** Jangan pernah mengirim password, OTP, PIN, atau informasi rahasia akun ketika meminta bantuan.
