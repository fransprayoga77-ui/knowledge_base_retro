Artikel ini menjelaskan arti status pada kartu dokumen vendor.

## Arti status

- **Approved** — dokumen telah disetujui pada portal.
- **Belum Upload** — belum ada file yang diunggah untuk jenis dokumen tersebut.
- **Review dilakukan admin backoffice** — pemeriksaan dokumen dilakukan oleh admin Adacar.

## Langkah-langkah

1. Buka menu **Dokumen Vendor** dan periksa status setiap kartu.
2. Untuk dokumen **Belum Upload**, tekan **Upload** dan unggah file yang benar.
3. Setelah mengunggah, tunggu review admin dan periksa kembali statusnya.

## Kendala umum

| Kendala | Solusi |
| --- | --- |
| Dokumen belum disetujui | Periksa jenis dokumen, kualitas file, masa berlaku, dan status review admin. |
