Halaman **Assignment Order** berisi order yang masuk ke vendor dan membutuhkan respons Anda.

## Langkah-langkah

1. Cari order menggunakan kolom **Cari order atau customer**, atau gunakan filter status.
2. Baca ID order, nama customer, rute, jadwal, armada, harga beli, dan alamat.
3. Tekan **Detail** untuk memeriksa informasi order lebih lanjut.
4. Jika Anda dapat memenuhi kebutuhan sesuai detail pesanan, tekan **Terima**.
5. Jika tidak dapat memenuhi pesanan, tekan **Batalkan** sesuai kondisi dan ketentuan operasional.

## Informasi pada kartu assignment

| Informasi | Keterangan |
| --- | --- |
| ID Order | Nomor unik order, misalnya ADO-261102-AKGN8. |
| Nama customer dan nomor kontak | Identitas pemesan. |
| Status | Misalnya **Menunggu Response** (assignment masih menunggu respons vendor). |
| Rute | Kota asal dan kota tujuan. |
| Jadwal | Tanggal dan jam perjalanan. |
| Armada | Model kendaraan dan jumlah unit yang diminta. |
| Harga Beli | Nilai harga beli yang ditampilkan pada kartu. |
| Alamat Jemput / Tujuan | Lokasi penjemputan dan tujuan perjalanan. |
| Peringatan armada | Muncul jika jenis unit belum terdaftar di armada vendor. |

## Yang perlu diperhatikan

> **Penting:** Jangan menerima order hanya berdasarkan model kendaraan. Pastikan unit, jadwal, lokasi, dan kapasitas benar-benar dapat dipenuhi.

## Kendala umum

| Kendala | Solusi |
| --- | --- |
| Assignment tidak ditemukan | Hapus kata kunci pencarian, ubah filter status, dan periksa kembali ID order. |
| Tidak dapat menerima assignment | Periksa status order, detail kebutuhan, ketersediaan unit, dan kemampuan pemenuhan vendor. |
